## ▶️ How to Run a Project

**Prerequisite:** Install GCC and ensure it is available in your terminal.

1. Clone this repository:

   ```bash
   git clone https://github.com/ballsohini939-alt/codealpha_tasks.git
   ```

2. Navigate to the project folder. For example:

   ```bash
   cd codealpha_tasks/CodeAlpha_MatrixOperations
   ```

3. Compile the source file:

   ```bash
   gcc matrix_operations.c -o matrix_operations.exe
   ```

4. Run the program in PowerShell:

   ```powershell
   .\matrix_operations.exe
   ```

**Note:** The source filename and executable name differ between projects. Open the selected folder and use its actual `.c` filename when compiling.
